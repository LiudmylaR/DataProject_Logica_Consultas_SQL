:ledger: Descripción del Proyecto\
Este proyecto recopila una serie de consultas SQL diseñadas para practicar la lógica de consultas y la manipulación de bases de datos relacionales, centrado en una base de datos para una tienda de películas. El proyecto tiene como objetivo demostrar el manejo de consultas SQL utilizando una serie de técnicas avanzadas para extraer y manipular datos de manera eficiente.

:pushpin: Objetivos del Proyecto
* Manejo de consultas SQL, simples y complejas: consultas basicas (SELECT, FROM, WHERE, AS), de agregación (MIN, MAX, COUNT, SUM, CONCAT, AVG, STDDEV, VARIANCE), de agrupación (GROUP BY, HAVING) y ordenación (ORDER BY, LIMIT, OFFSET), relaciones entre tablas (INNER JOIN, LEFT JOIN, RIGHT JOIN, CROSS JOIN, FULL JOIN), subconsultas (con WHERE, SELECT, FROM, EXIST, NOT EXISTS), vistas, estructuras de datos temporales (CTEs y tablas temporales).
* Uso de herramientas: PostgreSQL como motor de base de datos y DBeaver para la gestión de las consultas y la base de datos.
* Optimización y buenas prácticas: la claridad del código, la optimización de las consultas, el uso adecuado de índices, nombrado coherente, comentarios.

:white_check_mark: Resultados y Conclusiones\
Durante el desarrollo del proyecto DataProject: Lógica. Consultas de SQL  se aplicaron los principales conceptos del lenguaje SQL utilizando PostgreSQL y DBeaver.
Se lograron los siguientes resultados:
* Creación y gestión del esquema  de una base de datos relacional para una tienda de películas.
* Ejecución de consultas simples y avanzadas sobre una o varias tablas.
* Implementación de relaciones entre tablas mediante JOIN.
* Uso de subconsultas, vistas y tablas temporales para resolver consultas complejas.
* Aplicación de buenas prácticas en la escritura y optimización del código SQL.

El proyecto permitió reforzar los conocimientos de SQL y comprender la importancia de una buena estructura de base de datos para obtener información eficiente y coherente.
Se demostró el conocimiento de las consultas, el manejo de relaciones y la creación de vistas y subconsultas, consolidando una base sólida para futuros proyectos de análisis y gestión de datos.
